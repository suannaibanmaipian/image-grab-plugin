产品介绍

详情页保存图片，本来不该这么费劲

电商详情页的图片分散在主图区、卖点区、规格参数区、场景图区等多个模块里， 大多还是懒加载——不滚到那一段就不加载，右键另存只能一张张来。 一个 SKU 动辄几十张图，手工保存既慢又容易漏。

就算逐张保存下来，格式也往往是混的：主图是 jpg，详情图是 webp， 透明底图是 png。交给设计、客服或素材库时，还要再批量转一次格式。

图提取把这件事变成一步：点一下页面右下角的「获取图片」， 它会把当前页面里所有商品图扫描出来、过滤掉图标与占位图， 在新标签页里网格化排开并附带真实尺寸，你勾选完点一次下载， 得到的是一组编号整齐的 PNG 文件。

图片太分散

主图、详情长图、场景图分布在不同模块，还常常是懒加载，需要滚动触发。

没法批量保存

浏览器原生只支持一张张另存为，几十张图要重复几十次相同操作。

格式不统一

jpg、webp、png 混杂在一起，交付前还得再批量转一次格式。

核心功能

六件事，一次点完

从扫描到落地文件，全部自动完成。

一键提取

自动扫描页面所有商品图，兼容 img、srcset、data-src 与 CSS 背景图等懒加载写法。

智能过滤

自动排除图标、logo、占位图、1×1 像素图，以及小于 100×100 的小图，只留商品图。

集中预览

在新标签页用响应式网格展示全部图片，每张标注缩略图、真实尺寸与来源。

自由勾选

支持全选、反选、点卡片勾选，也能打开大图预览后单张下载，完全按需。

统一 PNG

jpg / webp / gif 自动通过 canvas 转换为 PNG，交付格式不再混杂。

批量下载

一键保存到默认下载目录，文件名按 商品图_001.png 自动递增编号，带进度与结果反馈。

安装步骤

四步装上，三十秒搞定

无需应用商店，从本地文件夹直接加载。

  1. 1

    下载插件并解压

    下载插件压缩包，解压到一个不会随手删掉的本地文件夹（例如 D:\tools\image-grab-plugin）。

  2. 2

    打开扩展管理页

    打开 Chrome，在地址栏输入 chrome://extensions 后回车。

  3. 3

    开启开发者模式

    点击扩展页右上角的「开发者模式」开关，页面会多出一排操作按钮。

  4. 4

    加载已解压的扩展程序

    点击左上角「加载已解压的扩展程序」，选中包含 manifest.json 的那个文件夹即可。

小提示：安装完成后，打开商品详情页会在右下角看到「获取图片」按钮； 如果页面早就开着，刷新一次即可。列表页、搜索页不会显示按钮。
